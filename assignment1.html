Internet & Web Fundamentals

A field guide to the 24 core terms every web developer should know — from the Internet itself down to the humble hyperlink. This page was built to practice text formatting, lists, images, anchors, and comments in HTML.

01The Internet

The Internet is a global network of interconnected computer networks that communicate using standard protocols such as TCP/IP.

  • ARPANET (1969) — one of the earliest packet-switching networks, and an important predecessor of today's Internet.
  • It connects computers, servers, smartphones, and countless other devices worldwide.

02The World Wide Web (Web)

The World Wide Web (WWW) is a collection of digital resources available via the Internet. It is a service that lets users access interconnected web pages through hyperlinks.

  • Invented by Tim Berners-Lee in 1989.
  • Relies on technologies such as HTML, HTTP, URLs, and web browsers.

03W3C — World Wide Web Consortium

The W3C develops and maintains standards and recommendations for the Web, including:

  1. HTML
  2. CSS
  3. Web accessibility
  4. Web architecture

04Web Page, Website, Home Page, Index Page & Landing Page

A web page is a single document on the Web, e.g. https://example.com/about.html.

A website is a collection of related pages under one domain, such as https://www.example.com, and may contain:

  • Home page
  • About page
  • Contact page
  • Services page
  • Blog pages

The home page is usually the main entry point (https://www.example.com/), while an index page (e.g. index.html) is the default file a server loads for a directory. They're related, but not always identical.

A landing page is built for one specific goal — register, buy, download, or submit a form — usually reached after clicking an ad or search result.

05Web Browser & Web Server

A web browser is software used to access and display web pages, such as:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

A web server stores, processes, and delivers web resources to clients. Common server software includes Apache, Nginx, and Microsoft IIS.

Browser ──HTTP Request──> Server
Browser <──HTTP Response── Server

06Web Domain, URL & URI

A domain name is a human-readable name for a site, e.g. www.example.com, used instead of a raw IP address like 93.184.216.34.

A URL specifies exactly where a resource is and how to reach it:

A URI is the broader concept: every URL is a URI, but a URI only identifies a resource, while a URL also tells you where and how to access it.

07HTTP, HTTPS, SSL & TLS

HTTP is the protocol used for communication between clients and servers, commonly over port 80.

HTTPS is HTTP protected with modern cryptography (mainly TLS), commonly over port 443. It provides:

  • Encryption
  • Authentication
  • Data integrity

SSL was an earlier security protocol — it has since been deprecated and replaced by TLS, the modern standard behind HTTPS today.

08HTML — HyperText Markup Language

HTML is the standard markup language used to structure web pages. Every page starts from the same basic boilerplate:

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Web Page</title>
</head>
<body>
  ...
</body>
</html>

09IP Address, DNS & nslookup

An IP address uniquely identifies a device on a network, e.g. 192.168.1.10 (IPv4) or 2001:db8::1 (IPv6).

DNS translates human-readable domain names into IP addresses:

www.example.com → DNS → 93.184.216.34

nslookup is a command-line tool used to query DNS information, e.g. nslookup example.com, and can reveal:

  1. IP addresses associated with a domain
  2. DNS server information
  3. DNS records

10Search Engines & ChatGPT

A search engine (Google, Bing, DuckDuckGo) helps users find existing information on the web:

Query → Search Engine → Search Index → Relevant Results → User selects a result

ChatGPT, developed by OpenAI, is an AI-based conversational system that generates responses, explanations, and code from natural-language prompts — rather than only retrieving existing pages.

11Hyperlinks / Links

  • One web page to another
